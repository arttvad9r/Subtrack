## Runtime hardening smoke

### Notification permission and payload

A debug-only receiver, excluded from release, can exercise the real notification
pipeline from adb.

On API 36:

- `POST_NOTIFICATIONS` denied -> 0 active Subtrack notifications;
- permission granted -> 1 active Subtrack notification;
- payload observed through `dumpsys notification`:
  - title: `Subtrack test notification`;
  - text: `19.99 $ · окончание 14 октября`.

The debug receiver requires `android.permission.DUMP` from the sender and is not
present in the merged release manifest.

### Process death / force-stop

A subscription created through the real UI test was inspected before and after:

```text
am force-stop com.arttvad9r.subtrack
am start -n com.arttvad9r.subtrack/.MainActivity
```

Room contained the same record on both sides:

```text
Persistent subscription|19900|RUB
```

### Device reboot

The emulator was rebooted with a real `adb reboot`.

After boot:

- Room still contained the subscription;
- logcat showed Android starting `BootReceiver` for `BOOT_COMPLETED`;
- `dumpsys alarm` showed the restored reminder alarm at local `09:00`.

For the test subscription the restored alarm was:

```text
2026-11-08 09:00:00 local time
```

### Timezone changes

The emulator timezone was changed to `America/New_York`, then restored to
`Europe/Helsinki` using `cmd alarm set-timezone`.

After each `TIMEZONE_CHANGED` broadcast the Subtrack alarm was rescheduled and
remained at `09:00` local time rather than retaining the old absolute instant.

### Large font / dark mode

The full Android instrumentation suite passed with:

- dark mode enabled;
- system font scale `2.0`.

The emulator was restored to font scale `1.0` afterwards. A visual sanity pass also confirmed that Russian UI dates use Russian month names even when the device locale is English (`11 ноября 2026`).
